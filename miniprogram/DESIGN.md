# 《Nianshu 的空间》小程序设计系统（00后向）

## 1. 设计定位

- 产品角色：内容型个人品牌小程序（博客 + 随笔 + 标签探索）
- 目标人群：00 后用户（高频刷内容、喜欢轻表达、重情绪价值和效率）
- 核心体验关键词：轻盈、真实、有记忆点、可连续阅读
- 设计原则：
  - 内容优先：先看到内容，再看到装饰
  - 情绪点缀：用小动效和微文案增加“陪伴感”
  - 快速决策：分类、标签、搜索路径要短

## 2. 主题风格（推荐主案）

主题名：`氧气感数字花园 2.0`

- 风格基调：清新自然 + 少量荧光感点缀
- 视觉气质：明亮、年轻、不幼稚
- 页面感受：像“会呼吸的阅读空间”，避免资讯站拥挤感

## 3. 色彩系统

优先使用浅色主题，保证微信内阅读舒适度。

- `--bg-page: #f6fbf9`
- `--bg-card: #ffffff`
- `--text-title: #0f1f1a`
- `--text-body: #24342e`
- `--text-sub: #64756f`
- `--line: #dfeae5`
- `--brand: #12a07f`
- `--brand-deep: #0d7f66`
- `--brand-soft: #eafaf5`
- `--accent-blue: #2e6bff`
- `--accent-violet: #6f5cff`
- `--tag-bg: #eef5ff`

使用建议：
- 主按钮、强调链接：`--brand`
- 互动状态（已收藏、活跃筛选）：`--accent-blue`
- 活动或专题推荐点缀：`--accent-violet`

## 4. 字体与排版

微信原生优先，保证加载性能与兼容性。

- 字体栈：`"PingFang SC", "Helvetica Neue", sans-serif`
- 标题：`34rpx / 700`
- 卡片标题：`30rpx / 650`
- 正文：`28rpx / 400`
- 辅助信息：`24rpx / 400`
- 正文行高：`1.75`
- 字距：标题 `0.2px`，正文默认

排版规则：
- 段落宽松，提升长文可读性
- 标题可换行，不做一刀切省略
- 文本块上下间距固定，减少跳动感

## 5. 布局系统

- 页面安全边距：`28rpx`
- 区块间距：`16/20/24/32rpx`
- 卡片内边距：`24rpx`
- 全局圆角：`16rpx`
- 触控最小高度：`88rpx`

### 页面级布局

1. 首页（`pages/index`）
- 顶部：品牌问候 + 搜索入口
- 中部：快捷入口（博客 / 随笔 / 标签）
- 下部：混合内容流（支持按“最新/热门”切换）
- 浮层：回到顶部 + 阅读进度

2. 列表页（`pages/posts`, `pages/essays`）
- 顶部：筛选条（最新、最热、最长阅读）
- 主体：信息卡片流（标题、摘要、标签、阅读时长）
- 底部：懒加载 + 空状态文案

3. 标签页（`pages/tags`）
- 顶部：标签热力区（按使用次数视觉分级）
- 下部：标签结果流
- 交互：点击标签后保留吸顶筛选条

4. 详情页（`pages/detail`）
- 顶部：标题 + 元信息（日期、阅读时长）
- 主体：Markdown 渲染正文
- 底部：相关推荐 + 下一篇
- 工具栏：点赞、收藏、复制链接、返回顶部

5. 关于页（`pages/about`）
- 个人简介、成长时间线、外部链接入口
- 支持“复制公众号/网站链接”一键操作

## 6. 交互与动效

00 后向交互重点：反馈快、动作轻、情绪化但不浮夸。

- 页面进入：`200ms` 淡入 + `8px` 上移
- 卡片点击：`120ms` 轻压（scale `0.98`）
- Tab 切换：底部指示条滑动
- 加载骨架：优先骨架屏，少用纯菊花
- 下拉刷新文案：可使用轻文案（如“花园浇水中…”）
- 空状态：图形 + 1 句鼓励文案 + 返回推荐按钮

可用微交互：
- 连续阅读 3 篇后提示“解锁今日漫游徽章”（轻激励）
- 首次收藏后出现一次性提示“已加入你的口袋书签”

## 7. 组件建议（优先抽离）

建议在 `components/` 新建：
- `garden-nav/`：统一页面头部
- `search-trigger/`：搜索入口按钮
- `content-card/`：通用内容卡片
- `tag-chip/`：标签胶囊
- `skeleton-list/`：列表骨架
- `empty-state/`：空态组件
- `action-bar/`：详情页底部互动栏

## 8. 功能清单（MVP -> 增强）

### MVP（建议优先完成）

- 内容浏览：首页混合流、博客列表、随笔列表
- 标签探索：标签列表 + 标签筛选
- 内容详情：Markdown 渲染、目录锚点（可选）
- 基础交互：下拉刷新、上拉加载、复制链接
- 搜索入口：标题/标签关键词搜索

### V1.1（体验增强）

- 收藏功能（本地存储）
- 阅读历史（最近阅读）
- 推荐系统（同标签相关文章）
- 主题切换（浅色 / 深色跟随系统）
- 分享海报（标题 + 二维码）

### V1.2（增长与运营）

- 每周精选合集
- 阅读成就（连续阅读天数）
- 订阅提醒（服务通知，可选）
- 数据看板（作者侧：热门文章、标签热度）

## 9. 文案语气（00后友好）

- 用词：真诚、简短、轻松
- 避免：过度鸡汤、过重营销话术
- 示例：
  - 加载中：`正在把内容搬进花园...`
  - 空状态：`这片区域还在发芽，先去别处逛逛吧`
  - 收藏成功：`收好了，随时回来继续看`
